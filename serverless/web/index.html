    What I can do

    One call covers the usual order questions

    • 01

      Track an order

      Where it is, which courier has it, and when it should arrive.

    • 02

      Cancel an order

      Stopped straight away if it hasn't shipped yet. Lumina tells you if it's too late.

    • 03

      Start a return

      Checks the return window and the item's condition, then starts it for you.

    • 04

      Ask for a refund

      Confirms you're eligible and starts the refund for the amount you paid.

    How it works

    Three steps, about a minute

    1. 1

      Press start

      Allow the microphone when your browser asks. Nothing to install.

    2. 2

      Say your order number

      For changes to an order, Lumina also asks for the email you ordered with.

    3. 3

      Get your answer

      Lumina checks the order and replies out loud. You can read along below the mic.
